## Overview

A computer-vision project for pedestrian tracking and attribute recognition, built as a pipeline of three components:

- **Detection** — YOLOX locates pedestrians in each frame.
- **Tracking** — DeepSort links detections across frames into consistent tracks.
- **Attribute recognition** — an MTAN model recognises pedestrian attributes.

The code is public on GitHub, and the repository includes a written report (`report.pdf`).
